Core Stack Operations

push(slot) O(1)

Adds a freed slot back to the TOP of the stack when a vehicle departs.

pop() O(1)

Removes and allocates the TOP available slot to the incoming vehicle.

peek() O(1)

Inspects the next slot to be allocated without removing it from the stack.

is_empty() O(1)

Returns True when all 20 slots are occupied (prevents stack underflow).

size() O(1)

Returns the current number of available slots in the stack.

Viva Preparation Guide

Q: Why use a Stack instead of a Queue for parking?

In real-world parking lots, when a slot near the front entrance is vacated, directing the very next car into that recently vacated slot minimizes searching time and optimizes flow. This follows LIFO (Last-Freed, First-Allocated).

Q: How does Python implement this stack?

Using a Python list with list.append() for push() and list.pop() for pop(), guaranteeing amortized $\mathcal{O}(1)$ time complexity for both operations.
